# Modern Digital Clock

A lightweight, performant, and responsive digital clock web application.

## Features
- Real-time time synchronization.
- Glassmorphism UI design.
- Full responsive support for desktop and mobile.
- Zero external dependencies.

## How to Run
1. Ensure all files (`index.html`, `styles.css`, `app.js`) are in the same directory.
2. Open `index.html` in any modern web browser.
3. No build step or server is required to view the UI.
